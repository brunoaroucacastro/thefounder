# Fluxo de trabalho do projeto

- O usuário autorizou manter este repositório atualizado a cada alteração solicitada no jogo.
- Explicar decisões de design com opções quando ainda não houver direção definida. Se o usuário pedir discussão antes de código, respeitar.
- Editar src/, executar node tests/game.cjs e gerar dist/ com node scripts/build.cjs.
- Registrar cada etapa no CHANGELOG.md e usar commits claros em português.
- Enviar as alterações ao GitHub e verificar o commit remoto. Se houver bloqueio, informar sem alegar publicação.
- Preservar saves quando possível; não publicar credenciais, dados pessoais, arquivos temporários ou configurações locais.
- Não afirmar validação visual quando apenas testes de lógica tiverem sido executados.
