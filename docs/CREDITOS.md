# Créditos

Créditos a dar no jogo (tela de créditos, página do jogo ou loja). Os autores saíram dos nomes originais dos arquivos.

A fonte e a licença ainda precisam ser confirmadas antes do lançamento. O padrão `autor-título-número.mp3` é o que o Pixabay usa nos downloads, então os efeitos provavelmente vieram de lá. Mesmo que o Pixabay não exija crédito, vamos creditar todos.
